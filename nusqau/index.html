5 Журнал аудита

Что запрашивали, какая модель и версия промпта, какая версия базы НПА, сколько стоило. В продукте — в БД, с пользователем и организацией.

Как это устроено

1. База знаний НПА. Пункты актов РК с id, текстом, редакцией и ссылкой на adilet. Модель получает выдержку по направлению и виду инструктажа.
2. Генерация. Модель пишет инструктаж и программу в JSON. Ссылки — только id из выдержки. Чужие id код отбрасывает, тезис без источника получает статус «непроверено».
3. Автосверка. Вторая модель-проверяющий сравнивает каждый тезис с текстом пункта (ok / partial / no) и оценивает практику (ok / doubt). Тест проверяется так же.
4. Человек. Методист правит, удаляет, утверждает. Тест и видео — только из утверждённой версии. Всё пишется в журнал аудита.

Демо: Cloudflare Workers AI, модель gpt-oss-120b, суточный лимит ниже бесплатной квоты. Видео в примере собрано локально: голос Windows (ru-RU), слайды из HTML, ffmpeg → MP4 1080p H.264 + SRT. В продукте — модели и синтез речи RU/KZ на серверах в РК. Посмотреть базу знаний демо.
